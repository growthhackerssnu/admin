# 대협 어드민 클릭 목업

PC 브라우저에서 업무 흐름을 검토하는 독립 정적 목업이다. 운영 서비스에 연결되지 않으며 실제 회사 조사·메시지 발송·Notion 저장을 하지 않는다. 화면의 발송 결과는 시연 데이터다.

## 실행

Python 3가 있는 환경에서 저장소 루트를 기준으로 실행한다.

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory prototypes/admin
```

브라우저에서 http://127.0.0.1:8765/ 를 연다. 이미 사용 중인 포트면 8766 등 다른 포트를 지정하고 같은 주소로 접속한다. 종료는 서버 터미널에서 Ctrl+C. Python이 없으면 이 폴더를 제공하는 정적 서버를 사용한다. 현재 저장소에는 package.json이나 npm 실행 스크립트가 없다.

React 18.3.1, ReactDOM, Ant Design 5.27.6, dayjs를 CDN에서 불러오므로 인터넷 연결이 필요하다. 현재 목업은 shadcn/ui가 아니다. API 키·DB·Slack 설정은 필요하지 않다.

## 저장과 초기화

브라우저 localStorage에 `dh-mock-v1`, `dh-cycles-v2`를 사용한다. 과거 목업의 `dh-mock-quarter` 키도 존재할 수 있다. 같은 브라우저·호스트·포트의 이전 시연 상태가 영향을 줄 수 있으므로 깨끗한 시연은 별도 브라우저 프로필을 사용한다. 저장 데이터는 다른 팀원과 공유되지 않는다. 실제 기업·관계자 정보를 입력하는 운영 도구로 사용하지 않는다.

## 검토 순서

1. 목록에서 경로와 작업 범위를 바꾸고 요약 패널·전체 상세를 연다.
2. 신규 → 수신자 선택 → 기존 샘플 초안 검토 → 시연 발송 → 이력에서 내용을 확인한다.
3. 동일 차수 무응답 기업의 추가 연락 제한과 다음 차수의 다른 관계자 제안을 확인한다.
4. 과거 거절·보류와 재협업에서 판단 정보·건너뛰기·제외의 차이를 확인한다.
5. 새 차수 시작 취소와 현재 차수 추가 탐색을 구분해 확인한다.
6. 배포 전 LinkedIn 샘플 브릿지랩에서 기존 담당자 제외를 확인한다.
7. 거절·보류 사유의 기타 설명, 발송 이력 열람을 확인한다.

이 목록은 팀원의 확인 절차이며 이번 PR에서 모든 브라우저 QA를 완료했다는 뜻은 아니다.

## 템플릿과 한계

`policy.js`에는 경로별 지정 템플릿의 null 슬롯만 있다. 미연결 상태에서 새 초안 생성이 막히는 것은 의도한 동작이다. 기존 초안은 검토할 수 있다. 원본 템플릿을 연결하기 전에는 전체 신규 생성 흐름을 끝까지 진행할 수 없다. 실제 AI 재생성도 연결하지 않았다.

`app.js`의 통합 객체·고정 사용자·샘플 ID·문자열 이력은 운영 DB 설계가 아니다. 인증, 동시 수정, 서버 오류 복구, 실제 동일인 식별, 수주 확정 화면, Notion 동기화는 구현하지 않았다. 남은 QA에는 수신자 변경 후 본문 인사말 확인 등이 있다.

[설계 인계 문서](../../docs/admin/README.md)에서 정책과 운영 연결 제안을 확인한다.
