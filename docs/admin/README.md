기준일: 2026-09-22. 이 문서는 웹 어드민의 업무 정책과 클릭 목업을 인계한다. 현재 운영 코드의 동작 설명은 [기존 구현 문서](../IMPLEMENTATION.md)를 참고한다.

## 문서의 지위

| 구분 | 범위 |
|---|---|
| 확정 업무 정책 | 수동 수주 차수, 경로별 판단, 동일 차수 무응답 기업 재발송 제한, 배포 전 접촉자 제외, 사유 카테고리 |
| 목업 구현 | 가상 기업을 이용한 클릭 흐름, 브라우저 저장, 발송 내용 이력, 경로별 템플릿 연결 슬롯 |
| 운영 구현 제안 | 웹 인증, 조회·변경 인터페이스, 동시 수정, 작업 조회, DB 모델 연결 |
| 미정 | 수주 확정 관리, Notion 동기화, 실제 발송, 관계자 평가 기준, 재접촉 초안의 맥락 반영 |

목업이 운영 기능의 구현 완료를 의미하지 않는다. 현재 Slack 서비스의 발송 정책도 변경하지 않는다. 연동 문서의 함수·필드·오류 코드는 제안이며, 사용 가능한 API가 아니다.

## 이번 PR의 범위

- `prototypes/admin/`: 기존 목업의 독립 실행용 사본. 실제 API 호출이나 발송 없음.
- `docs/admin/`: 최신 정책 및 협업 인계 문서.
- 루트 README: 위 자료로 가는 링크.
- 기존 서비스 코드, 패키지 의존성, DB 스키마, 환경 설정은 변경하지 않음.

다음 작업은 백엔드 담당자와 연결표의 차이를 합의한 후 기존 Next.js 구조에 웹 화면을 구현하는 것이다. 이전 로컬 설계 문서와 충돌하면 이 디렉터리의 최신 정책을 기준으로 논의한다. 초기 자료·일회성 수정 스크립트·실제 기업 원장은 포함하지 않는다.
