# 업무 흐름과 화면

## 관리 단위

기업을 중심으로 자료와 이력을 찾고, 작업 범위와 컨택 경로로 할 일을 좁힌다. 같은 기업의 이전 메시지를 덮어쓰지 않도록 기업과 차수별 컨택 건을 분리하는 안을 제안한다. DB 구조는 아직 합의 전이다.

전체 흐름: 수집 → 기업 검토 → 수신자 선택 → 메시지 초안·확정 → 발송 기록 → 응답·상태 관리. 수집·발송은 현재 목업 시연이며 실제 외부 작업이 아니다.

## 화면별 역할

| 화면 | 보여줄 정보와 행동 |
|---|---|
| 기업 관리 | 기업 중심 목록, 전체/리스트업/메시지 초안·확정/상태 관리 범위, 경로·담당자·검색 필터 |
| 새 기업 탐색 | 새 수주 차수 시작 또는 현재 차수 추가 탐색, 검색 조건 입력 |
| 요약 패널 | 기업 개요, 현재 상태·다음 행동, 최근 이력, 전체 상세 진입 |
| 상세: 이번 컨택 | 현재 작업에 필요한 판단 요약·출처, 수신자 선택, 초안 직접 편집, 응답 입력 |
| 상세: 기업 자료 | 언제든 참고하는 기업 조사·관계자 정보 |
| 상세: 발송·컨택 이력 | 행동 이력과 발송 당시 제목·본문·수신자·주소·시각 열람 |
| 운영 설정 | 정책 안내, 템플릿 연결 상태 등. 샘플 초기화는 목업 전용 |

상세의 탭은 참고 정보의 종류를 나눈다. 이번 컨택 내부의 상태는 순차 작업을 나타낸다. 별도 가로 단계 표시나 메시지 열기 버튼을 중복 배치하지 않는다.

## 경로별 시작과 다음 행동

| 조건 | 진행 | 중단·대기 |
|---|---|---|
| 신규 | 기업 판단 요약·출처 → 승인 → 수신자 → 초안 | 영구 제외. 신규 검토에는 차수 건너뛰기 없음 |
| 이번 차수에 발송 후 응답 미확인 | 사람이 응답 확인·기록 | 같은 기업의 사람·채널을 바꿔도 추가 발송 불가 |
| 이전 차수 무응답 | 실제 무응답 확인 → 다른 관계자 제안 → 다른 사람 선택 → 초안 | 이번 차수 건너뛰기 / 영구 제외 |
| 과거 거절·보류 | 이전 답변·사유·조건과 승인 메모 확인 → 기존 또는 다른 관계자 → 초안 | 이번 차수 건너뛰기 / 영구 제외 |
| 과거 협업 완료 | 이전 협업 기록 → 수신자 → 초안. 진행 사유 불필요 | 건너뛰기·영구 제외 시 사유 필수 |
| 현재 논의 중 | 리스트업에서 제외, 기존 기록 보존 | 논의·수주 결과의 별도 관리 방식은 미정 |

배포 전 LinkedIn 전용 이력 기업은 신규로 검토하되 기존 접촉자를 후보에서 제외한다. 과거 기록은 남긴다. 배포 후 발송·논의 이력과 섞인 기업은 무조건 신규로 바꾸지 않는다.

## 발송 이후

사람이 답변 없음/논의 시작/거절/보류/담당자 안내/연락 종료를 기록하는 화면이 있다. 수주 확정과 프로젝트 운영은 아직 포함되지 않는다. 내부 건너뛰기, 기업의 보류 답변, 영구 제외는 서로 다른 의미다.
